CRISP-DM Process Overview

Phase 1: Business Understanding

  • Mục tiêu: Dự đoán mức độ hài lòng khách hàng
  • Loại bài toán: Binary Classification
  • Ứng dụng: Cải thiện chất lượng dịch vụ

Phase 2: Data Understanding

  • Dataset: Customer satisfaction survey data
  • Số lượng mẫu: 1000+ records
  • Features: 20+ đặc trưng (dịch vụ, thông tin khách hàng)

Phase 3: Data Preparation

  • Xử lý missing values
  • One-hot encoding cho categorical variables
  • StandardScaler cho normalization
  • Train/Test split: 80/20

Phase 4: Modeling

  • Mô hình thử nghiệm: Logistic Regression, Random Forest, Gradient Boosting
  • Cross-validation: 5-fold CV
  • Hyperparameter tuning

Phase 5: Evaluation

  • Metrics: Accuracy, Precision, Recall, F1-Score, ROC-AUC
  • Confusion Matrix analysis
  • Feature importance analysis

Phase 6: Deployment

  • Flask web application
  • RESTful API endpoints
  • Interactive frontend
